# v0 demos

The original demos, produced by the pipeline as it stood before the correctness fixes
(see the paper's git history for the version they accompany).

They are kept for comparison only. Known issues: notes ran from one onset to the next, so
each swallowed the rest that followed it; source segments were cut to the target note's
length regardless of how long the source note was, so roughly half of them ran past the
end of the note they were selected for; frames were drawn at random from the ten nearest
pitches, leaving the melody up to two semitones out of tune; segments were butt-joined
without fades; and the mixes are hard-panned, with the reconstruction in one channel and
the original in the other.

The barnyard ones cannot be attributed: that collection's metadata was overwritten by the
violin run, so the Freesound sounds behind them are unrecoverable.
